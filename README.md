# Gloaming for desktop

Downloads and automatic updates for **Gloaming for desktop**: finished Instagram posts from your astro photos
(labels placed from a plate solve, fact-checked cards and captions, sky charts, Reels), and the nights to shoot them.

**[Download the latest version](https://github.com/DuffCorp/gloaming-releases/releases/latest)** for Windows, macOS or Linux.
Installed copies update themselves from here.

Working on an app that could hand images to Gloaming (AstroWizard, Siril scripts, your own tools)?
See **[INTEGRATIONS.md](INTEGRATIONS.md)**: an inbox folder, `gloaming://` links, a local API and a simple sidecar format.

This repository holds releases only; Gloaming's source code is private.
